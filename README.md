# Car Price Prediction Project

A Machine Learning project for predicting used car selling prices using multiple regression models and advanced feature engineering techniques.

The project focuses on data preprocessing, exploratory data analysis (EDA), feature engineering, model building, and performance evaluation using Python and Scikit-learn.

---

## Project Overview

This project analyzes car sales data to predict vehicle selling prices based on multiple features such as:

* Car Brand
* Manufacturing Year
* Transmission Type
* Odometer Reading
* Vehicle Condition
* Market Value (MMR)

The system applies Machine Learning algorithms to improve prediction accuracy and compare model performance.

## Machine Learning Models

The project compares multiple models including:

### 1. Linear Regression

Used as a baseline regression model.

### 2. Decision Tree Regressor

Captures nonlinear relationships in the dataset.

### 3. Random Forest Regressor

Improves prediction accuracy using ensemble learning.

---

## Feature Engineering

Custom engineered features include:

* Car Age
* Log Transformation of Odometer
* Odometer-Age Interaction
* Automatic Transmission Encoding
* Interaction Features

These features help improve model performance and prediction accuracy.

---

## Evaluation Metrics

The models are evaluated using:

* MAE (Mean Absolute Error)
* RMSE (Root Mean Squared Error)
* R² Score
